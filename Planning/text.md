# Required Equipment for the Project

## Core Components

1. **ESP32 Microcontroller**  
   Main controller for data processing, sensing, and communication.

2. **Current Sensor Module**  
   Used to measure current consumption and calculate power usage.

3. **Voltage Sensor Module**  
   Used to measure input or load voltage.

4. **10 uF Capacitor**  
   Used for basic filtering and voltage stabilization in the circuit.

5. **5V Relay Module**  
   Enables automatic ON/OFF switching of connected electrical loads.

6. **GSM Module**  
   Provides network communication capability (e.g., alerts/remote updates).

7. **Power Supply Unit**  
   Provides stable power to the ESP32 and other modules.

8. **16x2 Display Module**  
   Displays real-time current, voltage, and power consumption values.

9. **4N35 or 4N25 Optocoupler IC**  
   Provides electrical isolation and helps protect low-voltage electronics from surges.

10. **Fuse or Circuit Breaker**  
     Ensures circuit safety by protecting against overcurrent and short-circuit conditions.

11. **LED Bulb (Load)**  
     Used as a test load for switching and monitoring.

## Prototyping and Assembly Accessories

1. **Breadboard**
2. **Resistors**
3. **Jumper Wires**

These accessories are required for circuit prototyping, interconnection, and testing.
