## Monorepo Layout

```text
gighub/
├── app/              # React Native (Expo Router v6) mobile app — THIS project
│   └── documentation/  # ← you are here
├── web/              # Next.js 15 (App Router) — web frontend + REST API backend + admin panel
│   ├── schema/          # PostgreSQL/Supabase SQL migrations (source of truth for the DB schema)
│   └── data/schema/     # Design-time ER diagram, use-case diagrams (source material)
├── npm-types/        # @gig-hub/types — shared Zod schemas & TypeScript types (consumed by both app/ and web/)
└── main/             # Product planning docs (PRD, project brief)
```

## How to read this documentation

- Diagrams are written in [Mermaid](https://mermaid.js.org/) and render natively on GitHub, GitLab, and most Markdown viewers/IDE extensions.
- The database schema documented here is generated by reading the actual SQL migrations in `web/schema/*.sql` — treat that directory as the ground truth if this documentation and the code ever diverge; **re-run a documentation refresh whenever a new migration is added.**
- "Mobile app" / "the app" refers to `app/` (Expo/React Native). "Web app" / "backend" / "API" refers to `web/` (Next.js), which hosts both the public website, the admin panel, and every REST endpoint consumed by both clients.
